## 一句话总结

**用可穿戴的 A 超贴片（4 个小探头）连续追踪肌肉厚度，结合 IMU 测的关节角度，用一条简单的二次多项式就能"读出"肘关节和膝关节在发力时承受的力矩——实验室等速收缩误差 <7.6%、R²>0.92，并且第一次把这套测量搬出了实验室：举哑铃、骑单车、跑步机、甚至户外走路跑步。**

## 1. 研究背景：量化"身体内部负荷"为什么难（Introduction）

人体在运动中不断承受机械负荷，过度负荷会导致疲劳和损伤。量化内部负荷的应用：运动损伤预防、术后康复监测（损伤组织愈合期间要控制负荷）、外骨骼/助行机器人控制。但现有手段各有硬伤，论文的引言是一个漂亮的层层递进：

**组织层面**：

- 植入式力传感器：可以直接测肌腱/骨的力，但有创，人体研究基本不可行；
- 剪切波弹性成像（shear wave tensiometry）：机械敲击肌腱、测剪切波速来估计力——对跟腱、髌腱这类表浅突出肌腱有效，对深层/不突出肌腱未验证。

**关节层面**：

- 等速测力计（isokinetic dynamometer）：能直接测关节力矩，但人被固定在实验室设备上做标准化收缩；
- 逆向动力学 + 肌骨模型（OpenSim 类）：间接估计力矩/肌力，但需要动捕系统、测力台、大量计算——同样困在实验室。

**可穿戴替代品**（都不够"肌肉特异"）：

- sEMG：测的是肌肉的**电激活（神经输入）**，不是**机械输出**，受出汗、湿度、疲劳、神经疾病影响；
- MMG（机械肌图）：测肌肉收缩的侧向振动，同样有串扰和运动伪影；
- FMG（力肌图）：用一圈压力带测肌肉膨隆引起的皮肤压力变化——只能得到整条肢体的**净**形状变化，主动肌和拮抗肌混在一起；
- 软应变传感器：贴皮肤测局部形变，与力矩正相关，但同样**无法区分浅层和深层肌肉**。

> **肌肉特异性为什么重要（论文举的例子）**：腓肠肌既是踝跖屈肌又是膝屈肌（双关节肌），它下面的比目鱼肌只管踝跖屈。表面测量分不清这两块，功能解释就会错。

**超声的分层**：

- B-mode 超声：能提取肌肉特异的架构参数（厚度、肌束长度、羽状角），与肌肉力/关节力矩相关——但硬件和计算太重，仍困在实验室；
- **A-mode 超声（本文选择）**：单阵元探头、一维信号、测肌肉厚度，硬件和计算都轻得多。但此前只做过**静态等长收缩**下的握力/膝力矩估计，或受控等速肘屈伸——**动态、不受约束的真实场景从未被探索**。这就是本文要填的空白。

**第二条科学主线——肌肉架构问题**：骨骼肌分两类：

- **平行肌**（fascicles 沿肌肉长轴排列，如肱二头肌 BB）：收缩时横截面**均匀鼓起**，厚度变化与负荷直接对应；
- **羽状肌**（fascicles 斜着排在肌腱两侧，如股直肌 RF）：收缩时肌束**既缩短又旋转**，同一厚度可能对应多种负荷水平。

平行肌用 A 超测厚度追踪负荷讲得通；**羽状肌行不行是未解问题**——这是本文设计实验时特意对照的两块肌肉。

## 2. 系统与方法详解（Methods）

### 2.1 硬件：四探头斜角阵列（图 1）

- 4 个 5 MHz 单阵元探头（SET，Waygate Technologies），装在 35×43 mm 的 3D 打印外壳里，**角度分别为 0°、1.25°、2.5°、3.75°**，用压缩布带绑在目标肌肉上，探头组件总重仅 35.1 g。
- **为什么做多角度冗余**：超声回波强度在声束**垂直入射**（90°）到边界时最强。不同人的肌肉形状不同，运动中肌肉边界和探头的夹角还在不断变化——放 4 个不同角度的探头，就多 4 次"打正"的机会。这是对个体差异和动态运动的针对性设计（与 2018 交大论文的"多通道围一圈"思路同源，但更针对单块肌肉）。
- 采集链路：OPBOX 脉冲收发器 + 多路复用器（Optel, 波兰），探测深度 80 mm，**帧率 90 Hz**；电子设备电池供电、装进一个 5.4 kg 的背包（户外演示时背着）。

### 2.2 肌肉边界追踪算法 MBTA——本文的算法核心

任务：从 A 超回波里连续追踪肌肉上下边界的深度差（= 肌肉厚度）。难点：肌肉一变形，边界和探头的角度就变，回波强度跟着波动，单一追踪方法都会翻车。MBTA 的做法：

```
手动裁剪每个探头的关注深度范围
→ 从 4 个探头里选出平均峰值回波强度最大的那个（入射角最优）
→ 两种追踪方法融合：
   ① 亮度法：希尔伯特变换取包络 → 2D 盒滤波平滑 → 追踪峰值位置
      （能跟上边界的总体移动，但对回波强度波动敏感 → 高频噪声）
   ② 互相关法：相邻帧做互相关、逐帧积分相对延迟
      （平滑，但数值积分误差累积 → 低频漂移）
   融合：亮度法输出低通滤波(1.5 Hz) + 互相关法输出高通滤波(1.5 Hz) → 相加
→ 深层边界深度（追踪得到）− 浅层边界深度（手动测量视为常数）
   = 肌肉厚度
```

> 融合思路值得学：**一种方法的高频噪声恰好是另一种方法没有的，一种方法的低频漂移恰好是另一种方法没有的**——用两个互补滤波器各取所长。这是经典的传感器融合智慧。

**验证**：

- 台架测试（机械位移台 + 3D 打印曲面 + 人为改变回波强度模拟入射角变化）：RMSE 0.05 mm，NRMSE 0.5%；
- 在体验证（与 B 超金标准同步对比，等速膝屈伸）：RMSE 0.48 mm，NRMSE 1.7%——**小于大腿深层筋膜的平均厚度**，即追踪误差比肌肉下面那层筋膜还薄。

**实时性**：单帧计算 <0.3 ms（普通 i7 CPU），具备实时化潜力（目前是离线后处理；未来可用 FPGA、预定义感兴趣区域、滑动平均替代滤波等路径）。

### 2.3 力矩估计模型：简单到离谱的二次拟合

```
肘力矩 = f(肱二头肌厚度 MT, 肘角 Ang)    —— 二次多项式拟合，记作 (MT, Ang)²
膝力矩 = f(股直肌厚度 MT, 髋/膝角 Ang)    —— 同样的 (MT, Ang)²
```

为什么不用深度学习？作者的理由：

- 二次拟合**简单、可解释、泛化性和可迁移性好**（文献里二次、三次、指数、机器学习模型都有人用，这是引文 [64][65] 讨论的模型复杂度权衡）；
- **数据需求极低**：哑铃实验的估计器只用 **15 次等速收缩**训练（5 被动 + 5 向心 + 5 离心）。对比此前 A 超研究直接在原始数据上训练深度神经网络，需要大量训练数据。

先做特征提取（MBTA 把原始信号变成厚度这一个物理量），再套简单模型——和帝国理工那篇（RMS 特征 + 线性回归）的哲学一致：**让性能归因于信号和硬件，而不是黑箱**。

**真值处理的一个标准操作（值得初学者记下）**：测力计测到的力矩 = 重力力矩（肢体和附件重量造成）+ 生物学力矩（肌肉收缩造成）。作者用**被动收缩**时测得的力矩拟合出"重力力矩随角度变化的正弦函数"，再从所有数据里扣除——只留生物学力矩。

## 3. 实验与结果（Results）

实验矩阵是一个精心设计的递进：**受控验证（等速测力计）→ 功能任务（哑铃、骑行）→ 不受约束动态（跑步机）→ 真实世界（户外）**，每一步都换了肌肉和场景。

### 3.1 肘力矩 · 等速收缩（平行肌 BB，10 人）

- 协议：等速测力计，被动/向心/离心 × 3 速度（60/90/120°/s），每人 63 次收缩，关节活动范围 20°–110°。
- **个体化模型：RMSE 3.89 ± 0.86 Nm，NRMSE 7.6 ± 1.4%，R² 0.92 ± 0.03**。
- 收缩速度对误差无影响（p = 0.851）；被动运动误差显著低于主动收缩（被动时力矩本来就小，属预期）；向心 vs 离心无差异（p = 0.527）——模型对"发力方向"不敏感。
- **输入贡献消融**（关键实验）：

| 模型 | NRMSE | R² | 结论 |
|---|---|---|---|
| (MT, Ang)² 厚度+角度 | 7.6% | 0.92 | 基准 |
| MT² 只用厚度 | 9.6% | 0.87 | 略降、不显著 |
| Ang² 只用角度 | 25.8% | 0.10 | 崩溃 |

  → **对平行肌，厚度几乎足够**（肌肉鼓起直接对应负荷），角度本身几乎不含力矩信息。
- 通用模型（10 人数据合并训练，各人数据按最大值归一化）：NRMSE 11.5%，R² 0.82——比个体化差约 4%，但初步证明跨人可行。

### 3.2 肘力矩 · 哑铃弯举（走出实验室第一步）

- 5 人；先用测力计做标定（15 次收缩），再在 30° 斜凳上做自由弯举（无重量/中等/较重三种，如 0/5/10 kg）；肘角用两个无线 IMU 测。
- 标定模型：RMSE 2.62 Nm，NRMSE 6.8%，R² 0.96。
- 结果：估计力矩与经典力学**刚体模型**计算的力矩高度吻合；平均力矩的绝对误差 1.18–2.41 Nm，随重量成比例增加。
- 定性亮点：两种方法都得到**双峰力矩曲线**，峰出现在前臂与重力垂直（力臂最大）的时刻；第一个峰（伸肘段）幅度低——重力顺着运动方向。物理直觉完全自洽。
- 一个诚实的发现：估计值在峰值处**略高于**刚体模型。作者解释：刚体模型只算举起重量需要的力矩，不含**肌肉协同收缩**（co-contraction，关节两侧肌肉同时绷紧），而超声"看到"的是肌肉真实状态——超声可能比刚体模型更接近生理真相。

### 3.3 膝力矩 · 等速收缩（羽状肌 RF，10 人）

- 同样的等速协议，换成股直肌 + 膝关节。
- **个体化模型：RMSE 12.59 ± 3.12 Nm，NRMSE 7.0 ± 1.3%，R² 0.92 ± 0.02**——NRMSE 与肘相当（RMSE 绝对值大是因为膝力矩本身大得多）。
- **关键科学发现**：RF 厚度与膝力矩**相关但不单调**——厚度峰值和力矩峰值在时间上错位。这正是羽状肌的"可变齿轮"行为（肌束旋转），与 B 超文献一致。
- **输入贡献消融**：

| 模型 | NRMSE | R² | 结论 |
|---|---|---|---|
| (MT, Ang)² | 7.0% | 0.92 | 基准 |
| MT² 只用厚度 | 11.6% | 0.79 | **显著变差** |
| Ang² 只用角度 | 23.6% | 0.16 | 最差 |

  → **对羽状肌，厚度和角度必须联用**，且厚度贡献仍大于角度。这是全文最重要的科学结论：**输入变量的贡献取决于肌肉架构**。
- 探头位置敏感性分析（1 人、RF 上 18 个位置）：位置影响深层边界成像质量，但不剧烈改变与力矩的相关性；**但把一个位置标定的模型用到相邻位置，误差随距离增大** → 使用中必须防止探头漂移（老问题的新证据）。

### 3.4 膝力矩 · 骑行（肌肉特异性的展示台）

- 1 人；同时采**股直肌 RF + 股外侧肌 VL** 的 A 超 + IMU 膝角，不同骑行阻力。
- 结果：阻力增大 → 两块肌肉估计的力矩都增大，但**曲线形状不同**：VL 在下踏相位达峰，RF 在预备相位（下踏前）达峰——与已发表的 EMG 激活模式吻合。
- 机制：RF 是双关节肌（膝伸展 + 髋屈），VL 纯膝伸肌，功能分工不同。
- 这一节证明了超声的**肌肉特异性**——sEMG/MMG/FMG/应变传感器等一切表面测量都做不到区分两块相邻肌肉。

### 3.5 膝力矩 · 跑步机 + 户外行走跑动（不受约束动态）

- 5 人跑步机：走 0.75/1.25/1.75 m/s + 跑 2.50/3.00 m/s × 坡度 +10%/0%/−10%；真值 = 动捕（200 Hz）+ 测力跑台（2 kHz）做逆向动力学；RF 厚度 + 4 个 IMU（脚、小腿、大腿、骨盆）。
- **个体化模型：RMSE 17.43 ± 5.09 Nm，NRMSE 6.0 ± 1.1%，R² 0.92 ± 0.03**。
- 走 vs 跑误差无差异（p = 0.873）；坡度无影响（p = 0.965）。
- 输入用 RF 厚度 + IMU 骨盆/大腿/小腿角度——因为 RF 是双关节肌，髋角也影响其几何（等速测试时人被固定、髋角不变，所以没考虑；跑台/户外必须考虑。细节见功力）。
- **户外演示（1 人）**：同样的传感器布置，动捕标记摘掉，背上 5.4 kg 背包；平地慢走/快走/慢跑/跑 + 4.3° 坡的上/下坡行走和慢跑；**直接沿用跑步机上训练的模型**。
- 户外力矩趋势与跑步机一致：峰值力矩随速度增大（慢走→快走 +78.4%，跑步机对应 +71.3%）、上坡比下坡小（−20%，跑步机 −43%，差异来自户外坡更缓 −7.5% vs ±10%）——**模型跨环境迁移成功**。

## 4. 讨论要点与局限（Discussion）

**贡献总结**：

1. 受控收缩下 NRMSE <7.6%、R²>0.92，**优于**已有报告：EMG+A 超估计肘力矩 NRMSE 9.6%（引文 [47]）、软应变传感器估计膝力矩 15%（引文 [25]）；且首次拓展到不受约束的动态任务。
2. 应用图景具体：棒球投球/篮球传球/标枪等投掷动作的**肘负荷监测**（损伤预防）；膝骨关节炎、ACL 重建术后**社区环境下的膝负荷监测**；体力劳动的工效学（网球肘、职业性膝病）。
3. 肌肉特异性是相对于一切表面测量方法的差异化价值（骑行实验的 RF/VL 分工展示）。
4. 科学发现：平行肌 vs 羽状肌的输入贡献差异，与肌肉收缩的"可变齿轮"机制吻合。
5. 数据效率：二次拟合 + MBTA 特征，15 次收缩即可标定；未来 MBTA 特征 + 高级 ML（融合多肌肉测量）可更进一步。

**局限（作者自列 4 条）**：

1. 真值是**关节力矩**而非单块肌肉的力——后者无创直接测量不可行（这是领域级的测量学困境）；
2. 个体化标定仍依赖实验室设备（测力计/测力跑台）；通用模型只差 ~5%，但更易得的标定方案（如按体重估算）是未来工作——这同样是剪切波、应变传感器、sEMG 的共同需求；
3. 目前是离线后处理；实时化需要集中的同步采集系统（MBTA 本身够快）；
4. 只研究了**浅层肌肉**（BB、RF）和**铰链关节**（肘、膝）；MBTA 能追踪深层肌肉厚度（补充图 S1），但用深层肌肉动态估计力矩、以及球窝关节（肩、髋），均未探索。

## 5. 初学者概念速查表

| 术语 | 一句话解释 |
|---|---|
| 关节力矩（torque, N·m） | 关节处的旋转"劲"，= 肌肉力 × 力臂；本文的预测目标 |
| 平行肌 / 羽状肌 | 肌束沿长轴排列 / 斜排在腱膜两侧；收缩时均匀鼓起 / 缩短+旋转 |
| 肌束（fascicle）与羽状角 | 肌肉的"纤维束"及其与肌腱的夹角，B 超可测的架构参数 |
| 向心 / 离心 / 等长收缩 | 肌肉缩短发力 / 拉长中发力 / 长度不变的发力 |
| 等速收缩（isokinetic） | 设备强制关节按恒定角速度运动，测力计直接记录力矩 |
| 等速测力计（dynamometer） | 实验室"关节力矩金标准"设备，如 HUMAC Norm |
| 逆向动力学（inverse dynamics） | 由运动 + 外力反推关节力矩的经典生物力学方法 |
| 重力力矩 vs 生物学力矩 | 测力计读数 = 肢体自重贡献 + 肌肉收缩贡献；前者用被动收缩建模扣除 |
| MBTA | 本文的肌肉边界追踪算法：亮度法（高频准）+ 互相关法（低频稳）融合 |
| 包络 / 互相关 | 提取回波轮廓 / 比较相邻帧相似度估计边界位移，两种追踪的底层工具 |
| NRMSE | RMSE 除以真值力矩的量程，便于肘膝之间比较（本文 ~6–7.6%） |
| 双关节肌（biarticular） | 跨两个关节的肌肉：RF 管膝伸+髋屈；腓肠肌管踝跖屈+膝屈 |
| 协同收缩（co-contraction） | 关节两侧肌肉同时绷紧，产生额外关节负荷，刚体模型不含 |
| 刚体模型 | 用经典力学（质量、力臂、重力）计算理论力矩的简化模型 |
| IMU | 惯性测量单元，测姿态角；本文用于关节角度与步态分期 |

## 6. 整体评价

**强项**：

- Nature Comms 级的完整故事线：算法（MBTA）→ 受控验证（等速）→ 功能任务（哑铃/骑行）→ 真实世界（跑步机/户外），每一步都有对照和消融；
- **平行肌 vs 羽状肌的对照设计**让论文从工程报告升级为有科学结论的工作（输入变量贡献取决于肌肉架构）；
- 数据效率极高（15 次收缩标定），并诚实对比了深度学习路线的取舍；
- 应用面写得很落地（运动损伤、ACL 康复、工效学、外骨骼）。

**弱点**：

- 个体化标定仍依赖实验室设备，跨被试泛化只有初步结果（通用模型 NRMSE +4%）；
- 骑行、户外、位置敏感性都是单被试演示；
- 设备仍是"探头 + 线缆 + 5.4 kg 背包"的半可穿戴状态，离日常佩戴还有距离；
- 关节力矩真值与肌肉力之间的模糊性没有解决（模型学到的可能是"这块肌肉的厚度如何映射到整条力矩"，而非真实肌力）。

**一句话定位**：如果说前三篇证明的是"可穿戴超声能读懂你想做什么"，这篇证明的是"可穿戴超声能读懂你的身体正在承受什么"——两件事合起来，就是可穿戴超声作为通用人体传感器的完整图景。
