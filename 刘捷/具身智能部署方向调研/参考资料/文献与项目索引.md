## 3. 关键事实与证据位置

### 3.1 OpenVLA

- 7B 参数、OXE 约 970k 轨迹：论文摘要/方法；
- 动作离散 256 bin：论文方法；
- PMLR 270：CoRL 2024 论文集；
- 官方量化是 bitsandbytes，不是 TensorRT：代码/论文。

### 3.2 SmolVLA

- 约 450M：模型配置；
- SmolVLM-2 + 流匹配动作专家：论文方法；
- 异步推理/动作块：论文方法；
- 未核实正式会议页：arXiv 摘要页无 Comments。

### 3.3 Miki et al.

- Science Robotics 7(67): eabk2822：期刊页；
- 教师—学生/特权信息：论文方法；
- ANYmal 野外实验：论文实验；
- 不是人形/VLA。

### 3.4 VITA-VLA

- LIBERO 97.3%（+11.8）、LONG 93.5%（+24.5）、真机 82.0%（+17）：摘要；
- 两阶段动作专家蒸馏：方法；
- 无独立代码链接：摘要页仅项目页。

### 3.5 Evo-1

- 0.77B、2.3 GB、16.4 Hz、78%：论文 Table 2 / 真机实验；
- CVPR 2026 pp. 13397–13406：CVF 页面；
- xArm6，不是 G1；
- 不是蒸馏，是语义保持。

### 3.6 NaVILA

- RSS 2025 DOI 10.15607/RSS.2025.XXI.018：RSS 页面；
- 两级架构/中层语言动作：摘要与方法；
- 底层视觉运动策略：方法；
- 具体 G1/频率需查论文实验节。

### 3.7 Mobility VLA

- CoRL 2024，PMLR 270:3866–3887，正式年份 2025：PMLR 页面；
- 长上下文 VLM + 拓扑图：方法；
- 非人形。

### 3.8 Uni-NaVid

- RSS 2025 DOI 10.15607/RSS.2025.XXI.013：RSS 页面；
- 视频型 VLA/统一导航：摘要；
- 具体硬件/频率需查论文。

### 3.9 PredActor

- G1 + Orin NX；16.790 ms 中位数、19.383 ms p95、20 ms 周期：摘要；
- 44/45 目标、文本检索 0.539 vs 0.424：摘要；
- 未标注会议；代码未确认。

### 3.10 Embrace Collisions

- CoRL 2025：项目页；arXiv 摘要页无会议注释；
- 离散命令 + 实时全身控制、GPU 刚体仿真：摘要；
- 具体平台/DoF 需查论文。

### 3.11 ExBody

- H1 19DoF、CMU MoCap 780 段/约 3.7 小时、4096 环境：论文；
- 上身 9 关节 + 18 关键点；下身速度跟踪：方法；
- 真机 H1，不是 G1。

### 3.12 FoldQuantVLA

- W4A4/W8A8 原生 TensorRT 插件、AGX Orin/Ada：论文与 README；
- Orin 1.20–1.33×；W4A4 80.0% → 选择性 INT8 92.5%（80 trials/config，+1 ms）：摘要；
- Apache 2.0：仓库；
- Orin NX 与 AGX Orin 同为 sm_87，但性能不能直接外推。

### 3.13 SQIL

- ICCV 2025 Poster：官方页；
- 4-bit 权重、2.5× 加速、4× 显存、2.5× 能耗：官方页/项目页；
- QAT，不是纯 PTQ。

### 3.14 QVLA

- ICLR 2026 接收（2026-01-26）：README；
- 29.2% VRAM、98.9% 性能、1.49×：摘要；
- 当前代码是 weight-only fake-quant + checkpoint export，不是 TensorRT 原生。

### 3.15 MiniCPM-RobotTrack

- 官方 Go2 + Orin NX 部署；
- DINOv3/SigLIP TensorRT，主模型 PyTorch；
- 输出 waypoint/速度，不是关节；
- 官方验证 TensorRT 10.7；
- 非论文。

### 3.16 instinct_onboard

- G1 29DoF、50 Hz、ONNX Runtime、dry-run；
- 仓库无 ONNX 权重、无 LICENSE；
- Python 运行时；
- 依赖 `unitree_hg`、`crc_module`。
