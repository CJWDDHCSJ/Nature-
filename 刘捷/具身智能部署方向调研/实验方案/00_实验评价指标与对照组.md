# 实验评价指标与对照组规范

> 适用于五条主线的统一评测。没有对照组的“加速比”不进入结论；没有闭环成功率的“实时性”不进入简历主指标。

---

## 1. 为什么需要统一指标

同一个模型可能出现：

- FP16 单帧更快，但端到端更慢（预处理/传输占主导）；
- INT8 延迟更低，但动作抖动导致成功率下降；
- GPU 利用率更高，但控制周期抖动更大；
- 模型更小，但内存拷贝更多。

因此必须同时报告 **精度、延迟、资源、闭环任务** 四类指标。

---

## 2. 精度指标

### 2.1 感知/分类

- Top-1/Top-5 Accuracy；
- mAP；
- IoU；
- 每类召回率。

### 2.2 动作/策略

| 指标 | 定义 | 用途 |
|---|---|---|
| 动作 MSE | 预测动作与标签的均方误差 | 离线拟合 |
| 动作余弦相似度 | 动作向量方向一致性 | 量化前后对比 |
| 关节位置误差 | 每关节绝对/相对误差 | 控制精度 |
| 末端位姿误差 | 平移/旋转误差 | 操作任务 |
| 动作平滑度 | 相邻动作差分/二阶差分 | 抖动分析 |
| 越限率 | 超关节限位/速度限制的比例 | 安全 |

### 2.3 任务级

- 成功率（Success Rate）；
- 完成时间；
- 碰撞次数；
- 人工干预次数；
- 失败模式分布（停滞、越界、错误目标、抖动、通信中断）。

> 任务成功率必须给出测试次数、初始条件、评分标准。不能只报“效果很好”。

---

## 3. 延迟指标

### 3.1 定义

```text
t0 传感器曝光/状态采样
t1 输入张量就绪
t2 推理开始
t3 推理结束
t4 后处理完成
t5 动作下发
t6 执行器响应（可选）
```

- **纯推理延迟** = t3 − t2；
- **模型链路延迟** = t3 − t1；
- **端到端延迟** = t5 − t0；
- **控制周期** = 相邻 t5 的时间差；
- **抖动** = 控制周期的标准差/p95/p99。

### 3.2 报告要求

- warm-up ≥ 20 次，不计入统计；
- 至少 200 次连续推理；
- 报告 mean、p50、p95、p99、max；
- 区分首次加载/首次推理；
- 记录 GPU/CPU 频率与功耗模式；
- 记录是否与其他进程共享 GPU。

### 3.3 常见错误

- 只测一次；
- 不 warm-up；
- 把 GPU 异步执行当作完成（未同步）；
- 忽略图像解码/拷贝；
- 把 batch=1 的吞吐乘 batch 数；
- 不同精度的输入分辨率不一致。

## 4. 资源指标

| 指标 | 采集方式 | 备注 |
|---|---|---|
| 模型文件大小 | `du -h` | 含权重/引擎/插件 |
| 峰值 RSS | `/proc/<pid>/status` | 进程内存 |
| 峰值 GPU 内存 | `tegrastats`/`nvidia-smi` | Orin 统一内存需说明口径 |
| CPU 利用率 | `pidstat`/`tegrastats` | 分核心 |
| GPU 利用率 | `tegrastats` | 不是唯一瓶颈 |
| 功耗/温度 | `tegrastats` | 长时间运行必须记录 |
| 磁盘 I/O | `iostat` | 日志/模型加载 |

## 5. 对照组设计

### 5.1 量化对照

必须同一模型、同一输入、同一后处理：

| 组 | 权重 | 激活 | 校准 | 备注 |
|---|---|---|---|---|
| G0 | FP32 | FP32 | 无 | 精度上限 |
| G1 | FP16 | FP16 | 无 | 部署基线 |
| G2 | INT8 | INT8 | 有 | 标准 TensorRT |
| G3 | INT8+FP16 敏感层 | 混合 | 有 | 回退策略 |
| G4 | INT4 | FP16 | 有 | 权重量化 |
| G5 | INT4 | INT4 | 有 | 仅在插件可用时 |

### 5.2 模型对照

- 小模型 vs 大模型；
- 蒸馏学生 vs 无蒸馏学生；
- 分层 vs 端到端；
- 官方权重 vs 自己微调。

### 5.3 系统对照

- 同机推理 vs 跨机服务；
- CPU provider vs GPU provider；
- 同步 vs 异步/动作块；
- 有安全层 vs 无安全层（仅仿真）。

---

## 6. 统计与可复现

- 固定随机种子；
- 固定测试集/初始状态；
- 同一机器、同一功耗模式；
- 每个配置至少 3 次独立运行；
- 报告均值、标准差、样本数；
- 保存原始日志与配置；
- 提供一键复现脚本（不要求真机自动运行）。

---

## 7. 安全指标

| 指标 | 目标 |
|---|---|
| 关节越限次数 | 0（真机） |
| NaN/Inf 输出 | 0 |
| 状态超时检测延迟 | < 50 ms |
| 推理超时回退时间 | < 1 个控制周期 |
| 急停响应 | 独立于推理进程 |
| 故障注入恢复 | 100% 进入安全状态 |

## 9. 结论判定规则

- **加速有效**：p95 延迟显著下降，且成功率下降 ≤ 2 个百分点；
- **加速无效**：单帧下降但端到端无改善；
- **不可部署**：成功率下降 > 10 个百分点或出现安全事件；
- **需回退**：某层量化导致动作误差显著增大，保留 FP16；
- **仅离线可用**：无法满足控制周期，但可做高层低频推理。
