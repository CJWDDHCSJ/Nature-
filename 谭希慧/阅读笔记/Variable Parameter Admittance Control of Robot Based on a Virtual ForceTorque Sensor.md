# 《Variable Parameter Admittance Control of Robot Based on a Virtual Force/Torque Sensor》精读笔记

> **论文信息**：IEEE/ASME Transactions on Mechatronics, Vol. 31, No. 1, 2026 · 作者单位：华南理工大学
> **一句话总结**：为了解决协作机器人在人机交互时“拖动要柔顺”与“松手后要快速复位”的参数矛盾，设计了三种扰动观测器（FDO/GMO/KFO）进行无传感器力估计对比，并提出一种**根据速度动态调整刚度和阻尼的变参数导纳控制策略**，在 UR5 和 Franka 机械臂上完成了拖拽与轴承装配验证。

## 1. 问题与动机

**核心痛点**：
1. **硬件成本**：很多机械臂（如 UR5）没装关节力矩传感器或末端六维力传感器。加装成本高且增加负载。
2. **参数矛盾（最核心动机）**：
   - **拖拽阶段**：人推机器臂时，希望它像弹簧一样柔顺（刚度小，阻尼小）。
   - **松手复位阶段**：人松开手后，希望机器臂立刻僵硬并迅速回到目标轨迹（刚度大，惯量小）。
   - 传统导纳控制是“时不变”的，一组固定参数无法同时满足这两个截然相反的需求。

**作者的主张**：不需要真实力传感器，利用机器人的动力学模型和观测器计算出“虚拟力”；并且根据机器人的运动速度，**在线动态调整导纳参数**，完美兼顾柔顺拖动与快速复位。

---

## 2. 核心思想：三层递进

### 2.1 第一层：虚拟 F/T 传感器（三种观测器大比拼）
为了从电机电流（而非真实传感器）中估算出末端受到的外力，作者对比了三种扰动观测器（Disturbance Observer）：

1. **FDO (滤波动力学观测器)**：加入了低通滤波器，去掉了加速度 \(\ddot{q}\)（加速度噪声极大）。优点：计算极快，只有 \(O(n)\)。缺点：参数 \(\omega\) 难调，有相位滞后。
2. **GMO (广义动量观测器)**：基于动量残差，无需加速度。优点：计算快 \(O(n)\)。缺点：对模型误差敏感。
3. **KFO (卡尔曼滤波观测器)**：把外力建模为状态变量，用卡尔曼滤波进行最优估计。优点：**精度最高**。缺点：计算量极大 \(O(n^3)\)，参数极其难调（要调过程噪声和测量噪声矩阵）。

**结论**：如果用于碰撞检测，选 FDO/GMO（要求快）；如果用于高精度力控和导纳控制，选 KFO。

### 2.2 第二层：无传感器外力映射
通过观测器算出关节空间的扰动力矩 \(\tau_{ext}\) 后，利用雅可比矩阵转置的逆映射，将其转化为笛卡尔空间末端的六维力 \(F_{ext}\)：
\[
 F_{ext} = (J_{F}^{T})^{-1}\tau_{ext} 
\]

### 2.3 第三层：变参数导纳控制（核心贡献）
传统导纳方程：\(M_d \ddot{X} + B_d \dot{X} + K_d \tilde{X} = F_{ext}\)。
作者让 \(K_d\)（刚度）和 \(M_d\)（惯量）成为速度 \(\dot{X}\) 的函数：
\[
 K_{dvo,i} = \alpha K_{di} e^{|\dot{X}_i|} 
\]
\[
 M_{dvo,i} = \frac{M_{di} e^{-|\dot{X}_i|}}{\alpha} 
\]
- **物理直觉**：当外力撤除，机器人开始以较大速度回弹时，速度 \(\dot{X}\) 变大。此时刚度 \(K_{dvo}\) 指数级上升，惯量 \(M_{dvo}\) 指数级下降。机器人瞬间变得“极其僵硬且轻巧”，被强行拽回目标点。当到达目标点，速度降为0，参数恢复原状。

## 3. 关键实验与结果

### 3.1 观测器性能对比
在 UR5 上做圆周运动，人工施加外力。
- **精度**：KFO 的 RMSE 最小（误差在 4-5 Nm），FDO 和 GMO 较差（误差 5-15 Nm）。
- **计算时间**：FDO/GMO 约 0.35 ms，KFO 高达 1.94 ms（因为要算 5 阶泰勒展开的矩阵指数）。

### 3.2 变参数导纳控制实验 (UR5)
- **力响应延迟**：从检测到外力到机械臂开始动，延迟小于 0.3s。
- **复位速度提升**：加入变参数后，机械臂回到初始位置的时间大大缩短。\(\alpha=1.9\) 时，到达峰值的时间比传统恒定参数快了 0.64s。

### 3.3 真实应用：轴承装配 (Franka)
- Franka 自带关节力矩传感器，作者用其作为真值验证了虚拟 F/T 传感器的精度。
- 机器人成功完成了高精度的**轴承对孔（Peg-in-hole）和齿轮啮合**任务。拖拽阶段机器人保持柔顺（防止卡死），装配结束后迅速复位。

## 4. 批判性评价 (⚠️ 必须打问号的地方)

### 4.1 成立且漂亮的地方
1. **解决了非常真实的工程痛点**：做过协作机器人拖拽的人都知道，松手后机器人慢吞吞地“游”回原位的体验极差。用速度触发参数变化，逻辑简单且极为有效。
2. **详尽的观测器 benchmark**：FDO、GMO、KFO 的对比，把计算复杂度和调参难度都列出来了，对后人有很强的指导意义。
3. **李雅普诺夫稳定性证明**：虽然变参数控制看起来很“经验”，但作者给出了数学证明，保证了系统在参数突变时的稳定性。

### 4.2 我要打的问号
**(1) “虚拟传感器”严重依赖极其精确的动力学模型**
这套方法能成功，**绝对依赖于作者之前在论文 [10] 中做的极其精确的动力学参数辨识**。UR5 和 Franka 都是刚性极好的工业/协作臂，摩擦力规律相对稳定。如果换到柔性大、间隙大、或者负载经常变化的机器人上，动量残差会被模型误差（尤其是摩擦和惯性力）淹没，虚拟力将完全失去意义。

**(2) 基于速度的参数调节会导致“抖动”**
公式中 \(K_d\) 和 \(M_d\) 直接由瞬时速度 \(|\dot{X}|\) 决定。如果外力撤除时，传感器（或观测器）有一点点噪声，导致速度估计发生高频抖动，那么刚度和阻尼也会高频抖动，极其容易引发控制震荡。

**(3) 忽略了环境接触**
在轴承装配时，机器人不仅有外部拖拽力，还有环境对机器人的反作用力（接触力）。观测器无法区分“人推的力”和“撞到墙的力”。如果撞墙触发了“变参数快速复位”，可能会导致机器人以极大的刚度猛烈撞击环境，引发危险。

## 5. 与我的关系（Go2 视角）**⭐ 换位思考**

这是一篇**机械臂**的论文，离你的四足（Go2）比较远，但它的核心思想可以平移到四足上：

**平移思路：从“导纳控制”到“四足的柔顺交互”**
四足虽然没有机械臂，但如果你要在 Go2 上做**“人机物理交互”（如：人推狗、人拉狗牵引、或者狗用胸部靠住人保持安全距离）**，这篇的变参数导纳思想极其有用。
- **痛点**：如果你用纯位置控制（或者 RL 策略输出的速度指令），人推 Go2 会感觉像撞到一堵墙，或者机器狗为了维持原地站着，会和人“斗力”。
- **如何借鉴**：你可以将 Go2 的**基座速度**作为控制量。当人推 Go2 时（需要能测出虚拟推力），Go2 的基座速度指令 = 导纳方程输出的速度。外力大，它顺滑后退；外力撤除，由于变参数刚度的指数上升，它会迅速跑回原来的站立坐标。

**⚠️ 巨大风险（Go2 无法直接照搬的地方）**：
这篇论文用的机械臂是**固定基座（Fixed-base）**。Go2 是**浮动基座（Floating-base）**。Go2 的腿只要一落地，动力学就处于频繁的接触切换中，上面那三种观测器（FDO/GMO/KFO）在足式机器人上极难得到干净的外力信号（这也是我们前面看的另一篇论文要引入 QP 约束和 TCN 网络的原因）。

## 7. 精读自检清单

- [ ] 为什么固定基座机械臂可以直接用 \(F_{ext} = (J_{F}^{T})^{-1}\tau_{ext}\)，但四足不行？（因为四足有支撑腿的接触力耦合）。
- [ ] KFO 的 \(O(n^3)\) 复杂度在哪里？（状态矩阵的指数运算，即代码里的 `expm` 函数）。
- [ ] 变参数公式里，为什么 \(\alpha\) 越大越好？（因为它是放大系数，让松手后的瞬间刚度更大，复位更快，但太大可能导致电机过载）。
