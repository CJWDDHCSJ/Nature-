# 《Force-Aware Reinforcement Learning with Hybrid Sensorless Force Estimation for Wheeled-Legged Loco-Manipulation》精读笔记

> **论文信息**：arXiv:2609.13779v1 · IEEE Transactions on Mechatronics (推测)
> **一句话总结**：针对纯数据驱动力估计“缺乏物理结构”的问题，提出一种**混合无传感器力估计器**（广义动量观测器 GMO + 接触约束 QP 投影 + 时间残差网络 TCN 补偿）；将修正后的力显式输入给策略，结合**轴向力位掩码 (Axis-wise mask)**，在带轮腿足机器人上实现了自由空间、纯力控和混合力位控制。

## 1. 问题与动机

论文立论建立在之前工作的缺陷上：

1. **纯数据驱动力估计（如 UniFP 或 Portela）的缺陷**：完全依赖网络从历史本体感受中回归力，相当于让网络去隐式学习刚体动力学、支撑相切换、执行器摩擦等所有物理规律。这导致网络倾向于“平均化”（回归损失和神经网络的光谱偏差），在接触瞬态或高频力下容易失效。
2. **纯模型驱动（经典动量观测器）的缺陷**：在浮动基座（floating-base）系统中，全身动量残差包含了**支撑腿的反作用力、末端接触力、以及未建模误差**，这三者在广义坐标下严重耦合，很难用简单的伪逆（Pseudo-inverse）干净地分离出来。
3. **痛点**：轮腿机器人在做复杂接触任务（如拧阀门、擦黑板）时，既要保持基座稳定，又要输出准确的末端力。如何让 RL 策略获得一个**具备物理意义且精确**的力反馈表征？

## 2. 核心思想：三层递进的混合估计与策略控制

### 2.1 第一层：混合无传感器力估计 (Hybrid Sensorless Estimator)

这是本文最核心的工程贡献，彻底抛弃了“用神经网络直接预测力”的黑盒做法，改用**“物理模型打底 + 网络补偿”**的白盒/灰盒架构。分为三步：

1. **广义动量观测器 (GMO)**：利用关节指令力矩和本体感受，算出全身扰动残差 \(r\)。
   \[
 \dot{p} = u(q, v, \tau) + \dot{\xi} + K_1(p - \hat{p}) 
\]
2. **接触约束扳手投影 (Contact-Constrained Wrench Projection)**：
   已知 \(r = J_c^T \lambda_c + J_e^T w_e + \epsilon\)。作者不直接用伪逆求解，而是构建了一个**带约束的二次规划 (QP)** 问题：
   \[
 \min \frac{1}{2} \| W_q(r - Bx) \|_2^2 + \frac{1}{2} x^T R x \quad \text{s.t.} \quad A_c x \le b_c 
\]
   其中约束 \(A_c x \le b_c\) 包含了**单边接触约束和摩擦锥约束**。这一步极其巧妙，它强迫求解出的支撑力和末端力必须符合物理常识，防止支撑腿的误差“泄漏”到末端力上。
3. **时间残差学习 (Temporal Residual Learning)**：
   物理模型无法完美建模所有摩擦、惯性误差和柔性，所以用一个因果时间卷积网络 (Causal TCN, 历史窗口20步) 来学习 QP 投影后剩下的偏差 \(\Delta f_e\)。
   \[
 \hat{f}_e = \hat{f}_e^{obs} (\text{物理估计}) + \Delta \hat{f}_e^{res} (\text{网络补偿}) 
\]

### 2.2 第二层：力感知全身强化学习 (Force-Aware RL)

- **观测空间**：本体感受 + 行走指令 + 末端指令 + **估计出的末端力 \(\hat{f}_e\)**。
- **轴向掩码 (Axis-wise Cartesian task mask, \(m_t\))**：输入中有一个 3 维的 0/1 向量，控制每个轴是走“位置控制(0)”还是“力控(1)”。这跟 UniFP 的统一接口异曲同工，但本文是直接作用在奖励函数上：
  - \(r_{pos}\) 只在位置轴生效。
  - \(r_{force}\) 只在力控轴生效（利用仿真真值力计算奖励）。
- **多 Critic 架构**：将奖励拆分为 locomotion 和 manipulation，分别用两个 Critic 评估，防止目标冲突导致训练崩溃。

## 3. 关键实验与结果

### 3.1 估计器精度对比 (仿真, Table I)

作者对比了四种方法在三种惯性参数失配（\(\alpha_m = 0.8, 1.0, 1.2\)）下的误差：
- GMO-PI（传统伪逆）
- GMO-CQP（引入 QP 约束，无网络）
- TCN（纯网络预测，类似 UniFP 路线）
- **Ours（混合）**

**结果**：
- GMO-PI 误差极大（8.72 - 16.97 N），说明简单的伪逆完全无法解耦。
- TCN（纯学习）误差中等（3.96 - 6.28 N）。
- **Ours 误差最低（1.68 - 2.02 N）**，比 TCN 降低了 **57.6% - 71.0%**。
- 模型失配越严重（如 \(\alpha_m = 1.2\)），Ours 相对纯物理 GMO-CQP 的提升越大。

### 3.2 力控拖拽任务 (仿真, 对比 UniFP 与 Portela)

- **任务**：横向拖箱子，要求切向力跟踪正弦指令，法向保持 20N 压力。
- **结果 (Table II)**：
  - Portela 法：Y 轴误差 6.21N，Z 轴误差 12.69N（压得太狠）。
  - Zhi 法 (UniFP)：Y 轴误差 5.42N（力太小，箱子没怎么动）。
  - **Ours**：Y 轴误差 **0.98N**，Z 轴误差 **3.98N**，箱子被成功拖到了目标区域 `[-0.205, 0.220]`（目标 `[-0.2, 0.2]`）。

### 3.3 真机实验

在轮腿平台上测试了四个任务：拧阀门（原地和行进中）、混合力位擦黑板、拉开弹簧门、零力人机引导。
- 擦黑板任务中，法向力 15N，力控 RMSE 为 2.13N，估计器与 F/T 传感器的误差为 2.74N。
- 拧阀门时行进状态下的误差（5.82N）明显大于原地（3.99N），但依然能完成任务。
- 一个亮点：训练时力指令范围为 `[-10, 10] N`，但真机拧阀门用了 18N，开门用了 30N，居然也能工作（作者称之为“经验泛化”）。

## 4. 批判性评价 (⚠️ 必须打问号的地方)

### 4.1 成立且漂亮的地方
1. **物理与学习的结合极其优雅**。把 QP 约束引入扰动分离，再用 TCN 兜底，这正是解决“黑盒回归缺乏物理保证”的正确路径。Table I 的数据非常硬核地证明了这一点。
2. **彻底打脸纯学习路线**。TCN（纯网络）在失配下误差反弹严重，证明了“让网络去学全身动力学是低效的”。

### 4.2 我要打的问号
**(1) 平台红利：轮腿 vs 足式**
这是**Wheeled-legged**机器人。轮子提供了连续且平稳的支撑点，基座高度基本不变，动量观测器的平滑度极好。如果把同样的方法搬给**纯足式机器人（如 Go2）**，由于支撑相频繁切换（trot/walk），足端冲击会导致动量残差充满高频噪声，QP 和 TCN 还能不能稳住？这是一个巨大的疑问。

**(2) 强依赖精确的全身动力学模型**
GMO 和 QP 投影需要精确的惯性矩阵 \(M(q)\)、雅可比矩阵 \(J_c, J_e\) 以及电机力矩 \(\tau\)。Go2 这种高减速比、摩擦间隙大的足式机器人，往往拿不到精准的力矩 \(\tau\) 和 \(M(q)\)。这也是为什么这篇论文估计出的力能做到 1.68N，因为它的物理基线足够好。

**(3) 训练力范围过小，真机跨度大**
仿真训练力范围是 `[-10, 10] N`，但真机拧阀门用了 18N，开门用了 30N。虽然作者骄傲地说这叫“泛化”，但审稿人可以说：这恰恰说明小范围训练出的残差网络在超出范围后可能完全失效，真机能成功很可能是 QP 物理投影在兜底，没网络什么事。

**(4) 缺乏对估计延迟的讨论**
全身动量观测器 + QP + TCN 是串联的，500Hz 的观测器和 50Hz 的网络。整个估计链路延迟有多大？在接触瞬态（刚碰上的那一瞬间），延迟会直接导致 RL 策略过冲。

## 5. 与我的关系（Go2 视角）

这篇论文为你之前选的“**Go2 全身非抓取推挤（无臂身体操作）**”提供了一个极其强大的武器库。

**可以直接借鉴的：**
1. **残差思想**：Go2 没有腕部 F/T 传感器，如果只用纯 MLP 估力，精度肯定极差。你可以用**广义动量观测器 + 接触约束**算出“标称身体推挤力”，然后再用 TCN 补偿。
2. **验证了“估计精度不是越高越好”**：在拖拽任务中，纯网络 TCN 的误差（约 4N）和混合方法（约 1.7N）差距很大，最终体现为任务失败（Zhi 法没拖动箱子）和成功（Ours 拖动）。这为你做“精度-效用边界”提供了现成的方法论。

**必须绕开的坑：**
- **不要照搬它的网络输入**：它需要关节力矩 \(\tau\)。Go2 的底层可能不直接给力矩，你需要用关节电流拟合。
- **QP 投影在 Go2 上的病态性**：Go2 的腿比较短，雅可比矩阵在某些构型下容易奇异，QP 可能会解出无解或者剧烈跳变的力，必须做平滑。
